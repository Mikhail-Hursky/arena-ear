# Найденные звуки торговца Arena Breakout Infinite

Проверено и сохранено 27 октября 2026 года.

- **38 звуковых групп**: поднятие и опускание груза.
- **76 уникальных OGG-файлов**, суммарно 300 642 байта.
- **189 предметов-кандидатов** в таблице соответствий.
- Все 76 аудиофайлов успешно декодированы Web Audio в Chrome. Длительность: примерно 0,15–1,54 секунды.

Это полный набор открытого каталога торговца, который удалось проверить, а не полный набор всех звуков игры. Одинаковый звук может использоваться несколькими предметами разных редкостей. Для определения содержимого дополнительно нужны размер груза, карта/режим, категория и цена. Нельзя автоматически считать совпадение звука доказательством красного предмета.

## Источники

1. [ABI Tracker — Field Merchant](https://abi-tracker.azurewebsites.net/GameInfo/Merchant?lang=en): публичный звуковой каталог и используемые страницей медиафайлы. Адреса файлов получены из нормально загруженной страницы; вход и ключ не требовались.
2. [ABI Builder — Merchant](https://abibuilder.com/merchant): 38 групп, связи с названиями 189 предметов. Версия таблицы `1.0.0.151.10`; на ABI Tracker параметр версии медиа — `1.0.0.151.14`. Совместимость с будущими патчами не гарантируется.
3. [ABI Sound ID на GitHub](https://github.com/fizik888/Arena-Breakout-Infinite-ID-sound-checker/tree/main/sounds): дополнительный источник, на дату проверки содержит только 11 OGG-записей поднятия. Для этого набора использован более полный источник №1.

## Файлы

- `audio/`: оригинальные найденные OGG-записи.
- `audio-index.json`: события и соответствующие им аудиофайлы, источник и дата получения. 78 имён событий ссылаются на 76 уникальных файлов.
- `groups.json`: для каждой группы — pickup/drop и предметы-кандидаты с исходной числовой редкостью и размером. Это исходные данные, не формат импорта пользовательских эталонов Arena Ear.
- `files.json`: URL, размер и SHA-256 каждого сохранённого файла.

С 28 октября 2026 года все 76 файлов **автоматически подключены к распознавателю**. Копии для приложения находятся в `public/sounds/merchant`, каталог — в `src/data/merchant-groups.json`. Результат содержит звуковую группу и несколько кандидатов без общей метки редкости. Встроенная база отделена от пользовательского хранилища. Прослушивание и перетаскивание предметов доступны на странице `#/demo`.

Исходные файлы не являются собственными записями этого проекта. Происхождение сохранено в манифестах; публичная доступность сама по себе не означает открытую лицензию на их распространение.
