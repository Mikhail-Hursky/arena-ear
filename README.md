# Arena Ear

Локальный помощник для анализа звуков и сетки торговца **Arena Breakout Infinite**, созданный по публичному сценарию [Merchant Ear](https://abiear.ru/). Независимая реализация, не связанная с владельцем исходного сайта.

[Открыть приложение](https://mikhail-hursky.github.io/arena-ear/) · [Демо звуков](https://mikhail-hursky.github.io/arena-ear/#/demo)

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (по умолчанию `http://127.0.0.1:5173`).

```sh
npm test       # тесты алгоритмов и валидации
npm run build # TypeScript + production-сборка в dist/
npm run preview
```

Каталог `dist/` можно размещать на статическом HTTPS-хостинге. Захват экрана доступен только в безопасном контексте (HTTPS или localhost).

## Публикация на GitHub Pages

Приложение доступно по адресу **https://mikhail-hursky.github.io/arena-ear/**. Workflow [Deploy to GitHub Pages](.github/workflows/deploy.yml) при каждом push в `main` устанавливает зависимости через `npm ci`, запускает тесты, собирает приложение и публикует `dist/`. Его также можно запустить вручную во вкладке Actions. В Settings → Pages источником публикации выбран GitHub Actions.

Проверить сборку с тем же путём локально:

```sh
npm run build -- --base=/arena-ear/
npm run preview -- --base=/arena-ear/
```

Откройте `http://127.0.0.1:4173/arena-ear/`. Workflow задаёт базовый путь по имени репозитория; встроенные звуки используют этот же путь. Навигация через `#/demo` работает без серверной настройки маршрутов. Приложение остаётся полностью клиентским: записи и пользовательская библиотека не отправляются на GitHub.

## Основной сценарий

1. Дождитесь подготовки встроенной библиотеки: 76 настоящих OGG-записей, 38 групп и 189 предметов-кандидатов. Она подключается автоматически. В «Библиотеке звуков» можно дополнительно загрузить свои записи или записать подключённый источник.
2. В «Анализе груза» выберите карту и нажмите «Слушать игру».
3. В системном диалоге выберите источник с игрой и включите передачу звука. Если браузер передал только видео, приложение сообщит об этом.
4. Откройте торговца. При необходимости выделите область торговца мышью на превью, настройте её в «Настройках» или используйте ручную сетку.
5. Выберите ячейку в панели Arena Ear, затем перетащите соответствующий груз в игре. Звуковое событие сравнивается со встроенной и личной библиотеками.
6. Смотрите результат, сходство с эталоном и историю. Плавающее окно позволяет держать панель рядом с игрой.

## Демо звуков

Откройте «Демо звуков» в боковом меню или `http://127.0.0.1:5173/#/demo`. Зажмите предмет, перенесите в другую ячейку или рюкзак и отпустите: звучат реальные записи поднятия и опускания. Занятые ячейки меняются местами. Можно регулировать громкость, слушать действия отдельными кнопками, искать среди 189 предметов и выбирать любую из 38 групп.

Клавиатура: Пробел на предмете — поднять; Tab — перейти к ячейке; Enter — положить; Escape — отменить. При уходе со страницы звук останавливается. При входе в звуковое демо активный захват игры останавливается, чтобы звуки прослушивания не попадали в него.

Старое «Демо интерфейса» в анализаторе остаётся отдельной иллюстрацией: его результаты смоделированы и явно помечены. В «Демо звуков» воспроизводятся настоящие скачанные записи, а не синтетические тоны.

## Реализовано

- Захват окна/экрана и доступной аудиодорожки через Screen Capture API.
- Реальная запись PCM через AudioWorklet, выделение звукового события, экспорт записи WAV для создания образца.
- Локальный частотный дескриптор и сравнение с размеченными образцами, отказ от ответа при тишине, слабом или неоднозначном совпадении.
- Поиск контрастных границ сетки по кадру, поддержка прямоугольных объединённых ячеек и ручной режим.
- Picture-in-Picture при поддержке браузером; обычное всплывающее окно как резервный вариант.
- Библиотека образцов, проверка JSON при импорте, экспорт библиотеки и истории, настройки и локальное сохранение.
- Автоматическая подготовка 76 встроенных звуков с прогрессом и повтором при ошибке; результаты содержат группу и список кандидатов вместо ложного определения одного предмета.
- Отдельная звуковая песочница с перетаскиванием, поиском и прослушиванием всех групп.

## Ограничения

**Это независимое сравнение образцов, а не восстановленная закрытая модель оригинала.** Сходство — мера близости звука, а не вероятность содержимого груза. Для встроенных звуков показываются все предметы группы с их индивидуальной редкостью; группе не присваивается «красная» редкость. Для личного эталона используется ваша метка.

На точных исходных записях 74 из 76 сопоставляются с верной группой, а два похожих звука опускания (группы 11 и 16) консервативно возвращают неоднозначный результат. Это самопроверка библиотеки, **не оценка точности на звуке игры с фоновым шумом**. Встроенный каталог имеет версию `1.0.0.151.10` и может устареть после обновлений игры. Размер, карта и цена пока не фильтруют кандидатов автоматически.

Поиск сетки эвристический и работает с текущим видимым кадром. Решётка обнаружена на трёх кадрах публичной инструкции; точность границ всех предметов не подтверждена. Накопление всей сетки при прокрутке, OCR подписей и автоматическое определение наведённого в игре груза не реализованы. После прокрутки нажмите «Очистить сетку». Ячейку нужно выбрать в панели перед каждым звуком. Выбор карты задаёт контекст сессии и истории, не заменяет базу предметов.

Захват системного/оконного звука зависит от ОС, браузера и выбранного источника. Наличие `getDisplayMedia` не гарантирует аудиодорожку. Если она недоступна, можно анализировать сохранённые аудиофайлы. Приложение не подменяет системный звук микрофоном.

Обычное резервное окно не гарантирует отображение поверх полноэкранной игры. Режим Document Picture-in-Picture также зависит от браузера. Для практического использования может потребоваться оконный режим игры.

## Данные

Настройки, до 500 записей истории и до 500 личных звуковых эталонов сохраняются в localStorage этого браузера. Встроенные записи лежат в `public/sounds/merchant`, автоматически готовятся в памяти и не добавляются в личный экспорт или хранилище. Исходные пользовательские файлы не отправляются на сервер. При очистке данных браузера личные данные удаляются; пользуйтесь экспортом. Источники встроенной базы: [ABI Tracker](https://abi-tracker.azurewebsites.net/GameInfo/Merchant?lang=en) и [ABI Builder](https://abibuilder.com/merchant). Ключи исходного сайта не используются и не запрашиваются.
